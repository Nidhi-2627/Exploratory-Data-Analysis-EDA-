
🚢 Titanic Exploratory Data Analysis (Task 3)
This project performs a Mini Exploratory Data Analysis (EDA) on the famous Titanic dataset.
It focuses on deeper insights, improved data cleaning, and advanced visualizations to understand survival patterns.

📌 Objectives
Clean and preprocess real-world messy data
Perform advanced analysis using groupby
Discover survival trends based on multiple factors
Visualize insights to tell a data-driven story
🧹 Data Cleaning
Filled missing values in Age using mean
Dropped Cabin column due to excessive missing data
Filled missing Embarked values using mode
🔍 Analysis Questions
1. Survival by Age Group
Passengers were divided into age categories:

Child
Teen
Adult
Mid-age
Senior
👉 Children showed relatively higher survival rates.

2. Survival by Embarkation Port
C (Cherbourg)
Q (Queenstown)
S (Southampton)
👉 Survival rates varied based on boarding location.

3. Survival by Family Size
Family Size = SibSp + Parch
👉 Small families had better survival chances compared to large families or individuals traveling alone.

📊 Visualizations
The following charts were created:

📈 Histogram of passenger age distribution
🔥 Correlation heatmap of numerical features
📊 Bar plot of survival rate by family size

📊 Key Insights
Children had higher survival probability
Embarkation port influenced survival chances
Smaller families survived more than larger ones
Extremely large families had lower survival rates
